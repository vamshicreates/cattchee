# 👕 Cattchee ~ Catch The Tee
> **"We developed a game, but never launched!" — Now fully brought to life!**

**Cattchee** is a fast-paced, hypercasual mobile web game built for the quirky streetwear brand **T-SHIRTbaba**.

The core premise: T-shirts roll down the screen in conveyor lanes, and you must tap the matching tees based on dynamic prompts like *"Catch the red tee!"*. Every point you score directly converts into **₹ 1 off** your next t-shirt purchase!

---

## 🎮 Game Features
- ⚡ **Hypercasual Mobile Mechanics**: Silky-smooth 60 FPS conveyor lanes with responsive touch-and-tap controls.
- 🎯 **Dynamic Prompt Engine**: Prompts rotate between colors (*Red, Blue, Green, Yellow, Pink, Orange*), multi-catch streaks, and tricky speed rounds!
- 💸 **1 Point = ₹ 1 Discount**: Earn real, copyable discount voucher coupons (e.g. `BABA-OFF-35`) at game over.
- 🛍️ **Interactive T-SHIRTbaba Store**: Browse curated streetwear tees, apply your earned discount, and place orders directly on WhatsApp!
- 👑 **Special Bonus T-Shirts**:
  - **Golden Baba Tee**: Grants +₹10 instant bonus discount!
  - **Rainbow Tee**: Wildcard match that fits any prompt!
  - **Hazard/Stained Tee**: Avoid at all costs or lose a life!
- 🕹️ **Multiple Game Modes**:
  - **Classic 3-Lives**: Progressive difficulty with escalating conveyor speeds.
  - **60s Blitz (Sale Frenzy)**: Rapid-fire timed race against the clock!
  - **Weekly Baba Challenge**: High-stakes tricky prompt challenge!
- 🎵 **Pure Web Audio Synthesizer**: 0 external audio dependencies; custom procedural 8-bit chiptune BGM, combo pitch scaling, buzzers, and celebratory fanfares.
- 📱 **Mobile Haptics & PWA**: Mobile vibration feedback (`navigator.vibrate`), responsive safe-area insets, and instant fullscreen play.

---

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Audio Engine**: Web Audio API Procedural Synthesizer
- **Particles**: Canvas Confetti
- **Deployment**: Vercel

---

## 🚀 Local Development
```bash
# Clone the repository
git clone https://github.com/vamshicreates/cattchee.git
cd cattchee

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
